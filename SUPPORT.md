# Support

## Getting Help

If you need help with any of the 3 Leaps-supported open source projects, here are the best ways to get assistance:

### For Policy Questions
- **General inquiries**: Open an issue in this repository
- **Legal questions**: Contact legal@3leaps.net
- **Security issues**: See [SECURITY.md](SECURITY.md)

### For Project-Specific Support
- **FulmenHQ**: Visit [github.com/fulmenhq](https://github.com/fulmenhq) and check project-specific documentation
- **MDMeld**: Visit [github.com/mdmeld](https://github.com/mdmeld) for tool-specific support
- **Docemist**: Visit [github.com/docemist](https://github.com/docemist) for documentation tool support

### Response Times
- **Security issues**: Within 3 business days (see [SECURITY.md](SECURITY.md))
- **Policy questions**: Within 5 business days
- **General support**: Best effort basis

### Community Resources
- Check existing issues before creating new ones
- Review project documentation and wikis
- Consider contributing improvements (see [CONTRIBUTING.md](CONTRIBUTING.md))
